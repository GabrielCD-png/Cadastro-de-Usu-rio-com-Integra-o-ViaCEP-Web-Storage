# Cadastro-de-Usu-rio-com-Integra-o-ViaCEP-Web-Storage
Aplicação de cadastro desenvolvida com JavaScript. Utiliza a Fetch API para consultar o ViaCEP e preencher endereços automaticamente, além da Web Storage API (localStorage) para persistir os dados do formulário, evitando perdas ao recarregar a página. Projeto focado em consumo de APIs e manipulação do DOM.
